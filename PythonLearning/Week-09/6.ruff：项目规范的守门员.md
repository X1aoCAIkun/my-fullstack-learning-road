在上周我们已经学习过 ruff 是管理代码风格与检查代码的工具，本节是进一步巩固
uv add --dev ruff           # 加上依赖
uv run ruff check 文件路径          # 检查
uv run ruff check 文件路径 --fix      # 检查并自动修复错误
uv run ruff format 文件路径      # 格式化（替代 black），使代码风格标准化

在 pyproject.toml 的关键配置：
[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B", "SIM", "N"]
ignore = ["E501"]           # 不限制行长（line-length 已配）

规则代码        含义
E               pycodestyle风格错误
F               pyflakes未使用变量
I               isort import排序 
UP              pyupgrade升级老语法
B               flake8-bugbera易错点
SIM             简化建议
N               命名规范
