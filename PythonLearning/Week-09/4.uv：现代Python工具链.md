在之前 Week03 时讲到可以用 uv 快速地导入第三方包，接下来继续深入学习 uv

uv 由 ruff 同一团队（Astral）出品，用 Rust 写，比 pip / poetry 快10~100倍。一个工具同时是 pip / venv / pip-tools / poetry / pyenv

1. 安装 uv （macOS / Linux）
curl -LsSf https://astral.sh/uv/install.sh | sh

2. 新建项目
uv init mytodo          创建 mytodo 项目
cd mytodo               切换终端目录到 mytodo

3. 创建虚拟环境
uv venv

4. 加依赖（自动改 pyproject.toml + 装包）
uv add pydantic
 uv add --dev pytest ruff mupy

5. 安装所有依赖（按 uv.lock 锁定版本）
uv sync 

6. 跑命令（自动用项目地 venv）
uv run -m mytodo
uv run pytest
