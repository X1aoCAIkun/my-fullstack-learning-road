ruff 用 Rust 写，比 flake8/black/isort 快 10~100 倍。一个工具替代三个

pip install ruff
ruff check .          # 静态检查
ruff format .         # 自动格式化

在 pyproject.toml 文件：
[tool.ruff]
line-length = 100
target-version = "py312"

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B", "SIM"]  # 错误/未用/import 排序/升级语法/bugbear/简化

说白了 Ruff 是管代码风格、语法问题、未使用导入、格式；mypy 是管类型注解是否匹配
Ruff 可以提示会使程序出错的问题；mypy 的提示不会阻碍程序进行
